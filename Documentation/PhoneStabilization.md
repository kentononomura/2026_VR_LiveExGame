# スマホカメラの手振れ補正

TestSceneが生成する `Assets/VRCameraAssets/XROriginVR.prefab` の
`Right Hand Controller/VRPhoneCamera` に `VRPhoneStabilizer` を追加。
共通Prefabを使用する他シーンのスマホにも適用される。

## Inspectorでの調整

Prefab内のVRPhoneCamera、または実行中の同オブジェクトを選択し、
VR Phone Stabilizerコンポーネントを調整する。実行中の変更を保持したい場合は、
再生終了後にPrefab側へ同じ値を設定する。

| 項目 | 初期値 | 調整方法 |
| --- | --- | --- |
| Stabilization Enabled | ON | OFFで元の直接追従と比較 |
| Position Min Cutoff | 4 Hz | 下げるほど位置の補正が強くなる |
| Position Speed Coefficient | 4 | 上げるほど速い移動への追従が速くなる |
| Rotation Min Cutoff | 2 Hz | 下げるほど回転の補正が強くなる |
| Rotation Speed Coefficient | 0.025 | 上げるほど速い回転への追従が速くなる |
| Reset Distance | 0.5 m | 1フレームでこの距離を超えたら履歴を破棄 |
| Reset Angle | 90° | 1フレームでこの角度を超えたら履歴を破棄 |

まず左手でペンライトを振りながらON/OFFを比較する。
回転の揺れが気になる場合はRotation Min Cutoffを少し下げる。
構図変更が遅い場合はRotation Speed Coefficientを少し上げる。
速度係数を0にすると固定ローパスとして比較できる。
補正と追従遅延にはトレードオフがあり、速い揺れを意図した動作と完全には区別できない。

## 実装

- コントローラーの生の位置・回転を追跡空間内で取得し、速度に応じた一次ローパスを適用。
  位置は速度ベクトル、回転は角速度の大きさを1 Hzで平滑化してカットオフを調整する。
  One Euro Filterの考え方を使った姿勢用の適応フィルタであり、回転はQuaternion.Slerpで補間する。
- 元の取り付け位置・角度を補正後のコントローラー姿勢と合成するため、
  スマホ本体・画面・撮影カメラ・子UIが一緒に動く。
- 生の親Transformや入力バインドは変更しない。階層も維持し、永続XRリグへの移植に対応。
- LateUpdateで1回だけ履歴を更新し、XR追跡後のonBeforeRenderで同じ姿勢を再適用。
  描画直前に親の動きが伝わるのを打ち消し、複数回の描画でもフィルタを二重更新しない。
- 時間はunscaledDeltaTimeを使用。リグ全体の移動・回転は補正せず即時反映。
- 初回・再有効化・親の変更・大きな追跡ジャンプ・0.25秒超のフレーム停止では履歴をリセット。
- 無効化すると元の取り付け位置・回転へ復元。縦横UI判定は補正後のLateUpdateへ移動。

## 実機確認

1. 左手を静止／ペンライトを振る両条件で、スマホの位置・画面の揺れをON/OFF比較する。
2. ゆっくり構える動きと素早い構図変更で追従遅延を確認する。
3. 縦横持ち替え、ズーム、撮影画像の向きと構図を確認する。
4. ポーズ、リザルトからの復帰、リグ移動、トラッキング再取得で飛来・残留ずれがないことを確認する。
5. 画面の見やすさと不快感を確認して調整する。VR酔いの軽減は実機で未検証。

## 自動検証結果（2026-09-12）

- Unity 6000.5.1f1の参照アセンブリで変更したC#をコンパイル済み。
- 独立した検証用Unityプロジェクトのバッチテスト8項目が成功。
  初期配置、回転揺れの減衰、描画直前の再適用、リグ移動の即時反映、
  追跡ジャンプのリセット、OFF時の復元、ON時の初期化、コンポーネント無効化時の復元を確認。
- 初期設定で90 fps・8 Hz・振幅2度の正弦回転入力を与えた場合、
  定常状態のRMS振幅比は0.3735（約63%減）。実際の手振れやVR酔いへの効果を示す値ではない。
- 検証コードとログは一時ディレクトリ `Temp/PhoneStabilizerValidation` に配置。
  実機での撮影・縦横UI・シーン遷移の操作確認は未実施。
