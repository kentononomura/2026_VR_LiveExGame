# TestScene ペンライト・ハート応援機能 仕様

## 1. 目的

TestScene において、プレイヤーがペンライトを振る行為が「ユニティちゃんに気付いてもらいやすくなる」ことを、視覚演出とポイント計算の両方で分かりやすく伝える。

ペンライトを有効に振っている間は、ペンライトに光の軌跡とキラキラのエフェクトを表示し、一定間隔でハートをユニティちゃんへ飛ばす。ハートが到達すると、既存のペンライト色倍率に加えて、次の音声コマンド1回だけ追加倍率を適用する。

## 2. 対象範囲

- 対象シーン: `Assets/Scenes/TestScene.unity`
- 対象プラットフォーム: VR（Meta Quest を主対象とする）
- 対象ペンライト: TestScene で使用可能な左手ペンライト
- 既存の距離ポイント、ペンライトゲージ、色レベル、色倍率、音声認識、キャラクターリアクションを維持する。
- 右手はスマホカメラ用として扱い、本機能の対象にしない。

### 対象外

- プレイヤーがユニティちゃんを狙って振る必要のある照準・命中判定
- ハートが外れる、障害物に遮られる、途中で消失するゲーム性
- ハート到達倍率の複数スタック
- 他シーンへの導入
- 新しい音声コマンドやキャラクターリアクションの追加
- スコアの永続的な蓄積

将来拡張として、ペンライトの向き、振った方向、ユニティちゃんとの角度を使った照準・命中判定を追加できる責務分離にする。

## 3. 用語

| 用語 | 定義 |
| --- | --- |
| 有効振り活動 | 既存の `PenlightGaugeController` において、ノイズやトラッキングジャンプではなく、実際にゲージ加算へ寄与する振りを検出している状態 |
| ハート | ペンライト付近から発生し、ユニティちゃんの胸元へ追尾飛行する演出オブジェクト |
| 到達 | ハートが追尾時間を完了し、ユニティちゃん側の到達演出と追加倍率を発生させること |
| ハートボーナス | 到達後3秒以内に認識された次の音声コマンド1回へ適用する `x1.5` の追加倍率 |

## 4. 基本フロー

1. プレイヤーが左手ペンライトを振る。
2. 既存の有効振り判定がゲージ加算に寄与する動きを検出する。
3. 有効振り活動中、ペンライトに現在色の光の軌跡とキラキラを表示する。
4. 有効振り活動が続いている間、一定間隔でハートを1個ずつ生成する。
5. ハートは生成時のユニティちゃんの位置ではなく、現在の胸元位置を追尾して必ず到達する。
6. 到達時に胸元で小さなハート・キラキラ演出を再生し、ハートボーナスを3秒間有効にする。
7. 有効時間中に次の音声コマンドが認識された場合、既存ポイントへ `x1.5` を追加適用する。
8. その音声コマンドのポイント判定を行った時点でハートボーナスを消費する。判定結果が不成立でも再利用しない。
9. 3秒以内に音声コマンドが認識されなかった場合、ハートボーナスは失効する。

## 5. 有効振り活動と発生頻度

### 5.1 有効振り活動の開始

- `PenlightGaugeController` が既存の `AwardNewAmplitude` 相当の処理で、正のゲージ加算量を確定したときに有効振り活動を開始または継続する。
- コントローラーの微細な揺れ、設定値未満の振り幅、トラッキング復帰時の瞬間移動では開始しない。
- 判定は既存の `minimumSwingAngle`、`minimumSwingDistance`、`rotationNoiseDegrees`、`positionNoiseDistance`、`trackingJumpDistance` を尊重し、新しい別基準でゲージと演出が食い違わないようにする。

### 5.2 継続と終了

- 最後に正のゲージ加算を検出してから `0.30秒` を有効振り継続猶予の初期値とする。
- 猶予中に再度ゲージ加算を検出した場合は継続時間を更新する。
- 猶予を超えた場合は有効振り活動を終了し、連続エフェクトとハート発生タイマーを停止する。
- 振り始め、折り返し、ゆっくりした大振りでも、既存ゲージへ実際に寄与している限り活動を継続できること。

### 5.3 ハート生成間隔

- 有効振り活動が開始したとき、最初のハートを即時生成する。
- 継続中は `0.45秒` 間隔で1個ずつ生成する。
- 有効振り活動が終了しても生成クールタイムは維持する。次回の有効振り開始時は、直前の生成から `0.45秒` 以上経過していれば即時生成し、未経過なら残り時間後に生成する。
- 同一フレームで複数の振り判定が通知されても、生成数は1個までとする。
- 生成間隔と継続猶予は Inspector から調整可能にする。

これにより、振りを1往復するたびに無制限に個数が増える方式を避け、振っている時間に対して予測可能な上限を設ける。初期値では継続1秒あたり最大約2.2個となる。

## 6. ペンライト側の視覚演出

### 6.1 光の軌跡

- ペンライトの発光部または先端を基準に、現在のペンライト色に合わせた光の帯を表示する。
- 有効振り活動中に滑らかに表示し、活動終了後は短くフェードアウトする。
- 初期値は、軌跡保持時間 `0.20秒`、表示開始 `0.05秒`、終了フェード `0.15秒` とする。
- 軌跡はプレイヤーの視界を大きく覆わず、手元からユニティちゃんを見る妨げにならない太さと明度にする。

### 6.2 キラキラ

- 有効振り活動中、ペンライト先端付近から小さな粒子を断続的に発生させる。
- 粒子色は現在のペンライト色を基準とし、視認性確保のため白いハイライトを混ぜてよい。
- 有効振り活動の終了後、新しい粒子の発生を止め、発生済み粒子は自然消滅させる。

### 6.3 色変更への追従

- 白、青、黄、ピンクの各レベル変更を、その後に発生する軌跡、キラキラ、ハートへ即時反映する。
- 飛行するハートはペンライトのレベルにかかわらず、常に通常のピンク色とする。

## 7. ハートの飛行演出

- 飛行ハートは専用の `PenlightHeart` レイヤー（30）に配置し、通常のVR視界には表示する。
- スマホの `VRPhoneCamera` はこのレイヤーを描画対象から除外する。スマホ画面と保存写真は同じ RenderTexture を使うため、どちらにも飛行ハートは写らない。
- ペンライト本体、軌跡、手元や到達時のキラキラ、ハート到達判定・ボーナス処理は従来どおりとする。

### 7.1 発生位置

- 左手ペンライトの発光部中心を発生基準とする。軌跡・キラキラも同じ位置を使用する。
- 専用アンカーを設定できるようにし、未設定時は `SaberVisual` 配下の `Light` マテリアルに対応するサブメッシュのローカルBounds中心を使用する。発光部が見つからない場合はモデルのRenderer中心、Rendererもない場合はモデル原点を使用する。
- アンカーは発光部の子に配置し、モデルの位置・回転・スケールに追従する。モデル生成前は待機し、コントローラー前方32cmの固定位置には生成しない。

### 7.2 到達位置

- Humanoid Animator の `UpperChest` を第一候補、`Chest`、`Head`、ユニティちゃんのルート Transform の順でフォールバックする。
- 胸元ボーンにローカルオフセットを加え、見た目上の胸中央へ到達させる。
- 到達先は飛行中も毎フレーム再計算し、ユニティちゃんが移動・踊っていても追尾する。

### 7.3 軌道と時間

- 飛行時間の初期値は `0.80秒` とする。
- 発生位置から到達位置まで直線移動ではなく、上方向および横方向へ軽く膨らむ曲線軌道とする。
- 曲線の横方向はハートごとに左右を変えるか小さくランダム化し、完全に同じ軌道が重ならないようにする。
- 終点は常に現在の到達位置へ収束し、照準判定や物理衝突なしで必ず到達する。
- ハートはカメラ方向を向くビルボード表示とし、移動中に小さな脈動または回転を加える。
- ハートの大きさ、飛行時間、曲線量、発生間隔を Inspector から調整可能にする。色は通常のピンク色で固定する。

### 7.4 到達時

- 飛行ハートを非表示またはプールへ返却する。
- 胸元で小さなハートのポップとキラキラを再生する。
- 到達したハートは即座に消し、ボーナス有効時間中も胸元へ残留表示しない。
- ハートボーナスを有効化し、有効期限を到達時点から3秒後へ設定する。
- すでにハートボーナスが有効な場合、倍率は重ねず、有効期限だけを最新の到達時点から3秒後へ更新する。
- 到達演出の位置は到達した瞬間の胸元位置を使用する。

## 8. ハートボーナス

### 8.1 状態

ハートボーナスは次の3状態で管理する。

| 状態 | 内容 |
| --- | --- |
| `Inactive` | 追加倍率なし |
| `Active` | 到達後3秒以内で、次の音声コマンドを待っている |
| `Consumed/Expired` | 音声コマンドで消費、または時間切れ。直ちに `Inactive` 相当へ戻る |

- 保持できるボーナスは常に1回分だけとする。
- 飛行中のハートはボーナスとして数えない。
- 複数のハートが到達しても回数や倍率を蓄積しない。
- 有効中の新しい到達は残り時間への加算ではなく、期限を3秒へ更新する。
- 3秒はゲーム内時間基準とし、ポーズ中は減少させない。

### 8.2 適用対象

- 既存の完全一致または曖昧一致により `KeywordReaction` が確定し、`ExecuteReaction` が今回分の Voice Point 評価を行うタイミングで適用する。
- 空文字、未知語、候補が確定していない部分認識では消費しない。
- プレイヤーまたはユニティちゃんの Transform 欠落などによりポイント評価自体を開始できなかった場合は消費しない。
- 正常にポイント評価を実施した場合は、リアクションの成否にかかわらず消費する。

### 8.3 ポイント計算

既存計算を維持し、その末尾にハート倍率を追加する。

```text
基礎ポイント = 距離カーブ(プレイヤーとユニティちゃんの距離)
色適用ポイント = 基礎ポイント × ペンライト色倍率
最終ポイント = 色適用ポイント × ハート倍率

ハートボーナス有効時: ハート倍率 = 1.5
それ以外:             ハート倍率 = 1.0
リアクション成立条件: 最終ポイント >= 既存の成立閾値
```

既存初期値との組み合わせは次のとおりとする。

| ペンライト色 | 既存色倍率 | ハート到達後の合成倍率 |
| --- | ---: | ---: |
| 通常（白） | x1.0 | x1.5 |
| 青 | x1.2 | x1.8 |
| 黄 | x1.4 | x2.1 |
| ピンク | x2.0 | x3.0 |

- ハート倍率の初期値 `1.5`、有効時間の初期値 `3.0秒` は Inspector から変更可能にする。
- 色倍率とハート倍率は別の設定として保持し、既存の `normalMultiplier`、`blueMultiplier`、`yellowMultiplier`、`pinkMultiplier` を変更しない。
- デバッグログには、距離、基礎ポイント、色、色倍率、ハートボーナスの有無、ハート倍率、最終ポイント、消費結果、成立可否を出力する。

## 9. 到達後の表示

- 到達した飛行ハートはその場に残さず、到達時の短いポップとキラキラを再生した直後に消す。
- ハートボーナスの3秒間を示す常駐ハートや残光は表示しない。
- 既存の `VoiceReactionVisualFeedback` によるリアクション成立後のハート・キラキラ演出は維持する。

## 10. システム構成と責務

### 10.1 `PenlightGaugeController`

- 既存のゲージ加算、減衰、色変更、ハプティクスを維持する。
- 正のゲージ加算が起きたことと、その強度または加算量を外部へ通知できるようにする。
- エフェクト、ハート生成、音声ポイントを直接管理しない。

### 10.2 ペンライト演出・ハート送出コンポーネント（新規）

- 左手ペンライトの有効振り通知を受け取る。
- 有効振り活動の継続判定、光の軌跡、キラキラ、一定間隔のハート生成を管理する。
- ハートの発生元と追尾先を解決する。
- 飛行ハートをプールし、到達をボーナス管理へ通知する。
- TestScene 以外では自動的に動作させず、シーン上の明示的な配置または有効化を必要とする。

### 10.3 飛行ハート（新規）

- 1個のハートの曲線移動、現在の到達先への追尾、ビルボード表示、到達通知を担当する。
- ポイント倍率や音声認識へ直接アクセスしない。

### 10.4 ハートボーナス管理（新規）

- 到達時の有効化、3秒の期限更新、次の評価での1回消費、失効を管理する。
- 現在有効か、評価へ適用した倍率、残り時間を安全に問い合わせられるようにする。
- `VoicePointEvaluator` へ必要な値だけを渡し、視覚演出を直接管理しない。

### 10.5 `VoicePointEvaluator` / `TestSceneVoiceManager`

- `VoicePointEvaluator` は既存の距離・色計算に、今回のハート倍率を追加して最終ポイントを計算する。
- `TestSceneVoiceManager` はキーワード確定後、ポイント評価開始時にハートボーナスを1回だけ取得・消費する。
- ハート関連コンポーネントが未設定の場合は倍率 `x1.0` として従来どおり動作する。

## 11. Inspector 調整項目

少なくとも次の値と参照を Inspector から調整可能にする。

- 左手 `PenlightGaugeController` 参照
- ペンライト先端アンカー
- ユニティちゃん Animator またはルート Transform
- 胸元ローカルオフセット
- 有効振り継続猶予（初期値 `0.30秒`）
- ハート生成間隔（初期値 `0.45秒`）
- 軌跡の保持時間、幅、表示・終了時間
- キラキラの量、大きさ、寿命
- 飛行ハートの大きさ（または範囲）、飛行時間（初期値 `0.80秒`）、曲線量
- ハート到達エフェクト
- ハートボーナス倍率（初期値 `1.5`）
- ハートボーナス有効時間（初期値 `3.0秒`）
- 同時飛行数上限（安全値を初期設定）
- デバッグログの有効・無効

## 12. パフォーマンス要件

- ハートは事前生成またはオブジェクトプールで再利用し、発生ごとの `Instantiate` / `Destroy` を避ける。
- 軌跡、キラキラ、到達演出も再利用可能なコンポーネントまたは Particle System とする。
- 通常プレイ時に毎フレーム `Find`、`FindObjectOfType`、LINQ、Material 複製を行わない。
- 飛行中ハート数へ上限を設ける。上限到達時は最も古い飛行ハートを即時到達扱いにせず、新規生成だけをスキップする。
- ハート生成がスキップされた場合、追加倍率も発生させない。
- Meta Quest 実機でフレーム落ちや過度なオーバードローが発生しない粒子数・透明面積にする。

## 13. 異常系

- 左手ペンライトを取得できない場合は本機能だけを無効にし、音声認識と既存リアクションを継続する。
- ユニティちゃんの到達先を一時的に取得できない場合、ハートを生成しない。飛行中に参照を失った場合はボーナスを発生させず、ハートをプールへ戻す。
- ペンライト先端アンカーが未指定の場合は発光部中心を自動取得する。モデルが未生成の場合は生成を待つ。
- ハート素材または Particle Material を読み込めない場合は警告を1回だけ出し、利用可能なフォールバック素材を使用する。利用できない場合もポイント処理を停止させない。
- ボーナス管理参照がない場合は例外を出さず、既存計算の `x1.0` とする。
- シーン終了、コンポーネント無効化、ユニティちゃん再生成時はイベント購読と飛行中ハートを安全に解除する。
- ポーズ中はハート移動、発生、有効期限を停止する。

## 14. 受け入れ条件

1. TestScene で左手ペンライトを有効に振ると、現在色の光の軌跡とキラキラが表示される。
2. 微細な手ぶれ、閾値未満の動き、トラッキングジャンプだけではハートが生成されない。
3. 有効振り開始時にハートが1個生成され、継続中は初期値0.45秒ごとに1個ずつ生成される。
4. 振るのをやめると、初期値0.30秒の猶予後に新規ハート生成が停止する。
5. ハートは移動中のユニティちゃんの胸元を追尾し、初期値0.80秒で必ず到達する。
6. 飛行中のハートでは追加倍率が有効にならず、到達した瞬間から有効になる。
7. 到達後3秒以内の次の音声コマンド1回だけ、既存の距離・色倍率に加えて `x1.5` が適用される。
8. ボーナス適用後の音声ポイントが閾値未満でも、ボーナスは消費される。
9. 複数のハートが到達しても倍率は `x1.5` のままで、最後の到達から有効期限だけが3秒へ更新される。
10. 3秒間コマンドを認識しなければボーナスが失効し、その後のポイントは既存計算へ戻る。
11. 到達した飛行ハートは胸元に残留せず、短い到達演出後に消える。
12. ペンライトの色が変わると新しく発生する軌跡とキラキラは対応色になり、飛行ハートは常にピンク色を維持する。
13. 既存の色倍率、ゲージ減衰、レベルアップ時ハプティクス、音声認識、成立後リアクション演出が従来どおり動作する。
14. ハート関連参照や素材が欠けていても、既存の音声認識とリアクション処理で例外が発生しない。
15. Quest 実機で連続して振っても、目立つフレーム落ち、GC スパイク、視界を塞ぐ過剰なエフェクトが発生しない。

## 15. 確認用テストケース

| 操作・条件 | 期待結果 |
| --- | --- |
| 左手を静止 | エフェクトとハートを新規発生させない |
| 閾値未満の小さな手ぶれ | ゲージ加算もハート生成も行わない |
| 有効な振りを開始 | 軌跡とキラキラを開始し、ハートを即時に1個生成 |
| 2秒間振り続ける | 生成間隔に従ってハートを生成し、毎フレーム生成しない |
| 振りを止める | 継続猶予後に発生を止め、軌跡をフェードアウト |
| ハート飛行中にユニティちゃんが移動 | 胸元を追尾して到達 |
| ハート飛行中にスマホを向けて撮影 | VR視界にはハートが見え、スマホ画面とギャラリーの保存写真には写らない。到達時のボーナスは有効になる |
| ハート飛行中に音声コマンドを認識 | そのハート分の追加倍率は適用しない |
| ハート到達から2秒後に音声コマンドを認識 | 色倍率に加えて `x1.5` を適用し、1回で消費 |
| ハート到達から3秒超過後に音声コマンドを認識 | `x1.5` を適用しない |
| ボーナス中に複数ハートが到達 | 倍率は増えず、最後の到達から3秒へ期限更新 |
| ボーナス適用後すぐに別コマンドを認識 | 2回目は `x1.5` を適用しない |
| ボーナスを使ったがポイント不足 | リアクション不成立、ボーナスは消費済み |
| 未知語または未確定の部分認識 | ボーナスを消費しない |
| ペンライト色を白から青・黄・ピンクへ変更 | 軌跡とキラキラだけが対応色になり、飛行ハートはピンク色のまま |
| ポーズを開いて3秒以上待つ | 飛行とボーナス残り時間が進行しない |
| ハート関連コンポーネントを無効化 | 従来の距離×色倍率で音声リアクションが動作 |

## 16. 将来拡張方針

狙ってハートを飛ばす仕様へ拡張する場合は、ハート生成前に「ペンライト先端方向と胸元方向の角度」「振り方向」「許容角度」を評価する命中判定を追加する。飛行表示、到達通知、ボーナス管理、Voice Point 計算は今回の構成を再利用し、命中判定だけを交換・追加できるようにする。
