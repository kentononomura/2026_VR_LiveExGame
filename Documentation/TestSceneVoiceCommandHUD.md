# TestScene ボイスコマンド HUD 仕様

## 1. 目的

TestScene で使用できるボイスコマンドを、プレイヤーの視界右側へ常時表示する。
音声認識によってコマンドが確定し、対応するキャラクターリアクションが実際に成立した場合、そのコマンド項目を一時的に強調表示する。

## 2. 対象範囲

- 対象シーン: `Assets/Scenes/TestScene.unity`
- 対象プラットフォーム: VR（Meta Quest を主対象とする）
- 表示言語: 日本語のみ
- UI はプレイヤーの頭の動きへ滑らかに追従する、視界固定型の World Space HUD とする。
- HUD は TestScene の滞在中、常時表示する。

### 対象外

- 左トリガーの操作案内
- 「認識中」「認識失敗」などの音声認識状態表示
- HUD の表示・非表示切り替え操作
- 内部コマンド「デフォルト」の表示
- 他シーンへの HUD 導入

## 3. 表示内容

HUD の見出しを「ボイスコマンド」とし、次の4項目を上から順に表示する。

| コマンドID | 表示文字列 | 主な認識語 |
| --- | --- | --- |
| `LookAt` | こっち向いて | こっち向いて、こっち見て |
| `Wave` | 手を振って | 手を振って、手振って |
| `Cute` | かわいい | かわいい、可愛い |
| `UnityChanCall` | ユニティちゃん | ユニティちゃん、ユニティーちゃん |

認識語の表記ゆれを複数行で見せる必要はなく、プレイヤー向けの代表表現だけを1項目につき1つ表示する。

## 4. 配置と追従

### 4.1 基準位置

- 基準は `Camera.main` の HMD カメラとする。
- HUD 中心を、カメラ正面から約 `2.0 m`、視界中心から右へ約 `0.75 m`、下へ約 `0.05 m` の位置に置く。
- 上記は初期値とし、距離・水平オフセット・垂直オフセットを Inspector から調整可能にする。
- HUD 正面は常にカメラ側を向き、文字が裏返らないこと。

### 4.2 追従方式

- カメラの位置と回転を毎フレーム参照し、位置・回転を補間して滑らかに追従する。
- 追従速度は Inspector から調整可能にし、初期値は既存の `VRFaceLockedUI` と同等の `5.0` とする。
- 頭部の微細な揺れで HUD が振動して見えないよう、追従先へ瞬間移動させない。
- シーン開始直後の最初の配置だけは即時に行い、遠方から HUD が飛来する見え方を防ぐ。
- 水平オフセットはカメラのローカル右方向を基準に計算し、プレイヤーが向きを変えても常に視界右側を維持する。

## 5. ビジュアル仕様

デザイン指定がないため、ステージを邪魔せず日本語を読みやすくする中立的な初期デザインとする。

- 半透明の暗色パネルに白文字を使用する。
- 見出しと4項目を縦方向に配置する。
- 文字には TextMeshPro を使用し、日本語グリフを含む既存フォントアセットを優先する。適切な既存アセットがない場合は、日本語対応 TMP フォントアセットを用意する。
- 1項目は「背景」「表示文字列」で構成し、強調表示を項目単位で変更できる構造にする。
- パネル、余白、行間、文字サイズは World Space Canvas の実寸と Quest 実機で調整可能にする。
- 通常項目は白文字、低コントラストの透明背景とする。
- 強調項目は暖色系のアクセント色を初期値とし、背景色・文字色・拡大率を Inspector から変更可能にする。
- 画面中央のキャラクターや既存の右手スマホ表示と過度に重ならないことを実機確認する。

## 6. 強調表示の動作

### 6.1 発火条件

次の条件をすべて満たしたときだけ強調を開始する。

1. Vosk の認識結果が既存の完全一致または曖昧一致判定を通過する。
2. `KeywordReaction` が確定する。
3. `ExecuteReaction` 内の Voice Point 判定を通過する。
4. 表情、体、目線のいずれかのキャラクターリアクションが実際に開始される。

部分認識中、候補一致中、Voice Point 不成立時、未知のコマンド、内部コマンド `Default` では強調しない。

### 6.2 表示遷移

- 成立したコマンドIDに対応する1項目だけを強調する。
- 強調開始時に、背景色と文字色をアクセント色へ滑らかに遷移させ、項目を `1.08` 倍まで軽く拡大する。
- 強調のフェードイン初期値: `0.12 秒`
- 強調の保持時間初期値: `1.5 秒`
- 通常状態へのフェードアウト初期値: `0.35 秒`
- 時間は `Time.unscaledDeltaTime` 基準とし、ゲーム側の時間倍率に影響されないようにする。
- 同じコマンドが再成立した場合は、その時点から強調時間を再開始する。
- 別のコマンドが成立した場合は、以前の項目を通常状態へ戻し、新しい項目を強調する。同時に複数項目を強調しない。
- HUD が無効化された場合はアニメーション状態を破棄し、次回有効化時は全項目を通常状態から開始する。

## 7. システム連携

### 7.1 責務分離

- `TestSceneVoiceManager` は、リアクション成立後に確定した `commandId` を通知する責務だけを持つ。
- HUD 側コンポーネントは、コマンドIDと表示項目の対応付け、追従、表示、強調アニメーションを担当する。
- HUD が未配置または無効でも、既存の音声認識、キャラクターリアクション、視覚エフェクトは従来どおり動作する。

### 7.2 通知位置

通知は `TestSceneVoiceManager.ExecuteReaction` の `reactionStarted == true` が確定した箇所で行う。既存の `VoiceReactionVisualFeedback.Play` と同じ成立条件を使用し、音声が認識されただけで強調される状態を避ける。

通知値には `KeywordReaction.commandId` を使用する。値が空の場合のフォールバック名は視覚エフェクト用には維持してよいが、HUD は未定義IDを無視する。

### 7.3 推奨構成

- 新規 HUD 制御コンポーネントを作成し、TestScene の専用 Canvas に追加する。
- HUD 制御コンポーネントは4項目を直列化された設定として保持し、各設定に `commandId` と対象 UI 参照を持たせる。
- `TestSceneVoiceManager` から HUD への参照は任意設定とし、未設定時は TestScene 内から一度だけ自動検索するか、通知を安全に無視する。
- 毎フレームの `Find` や LINQ による割り当てを避ける。
- 強調処理中に GameObject、Material、文字列などを繰り返し生成しない。

## 8. Inspector 調整項目

少なくとも次の値を Inspector から調整可能にする。

- カメラからの距離
- 右方向オフセット
- 高さオフセット
- 位置追従速度
- 回転追従速度
- 通常時の背景色・文字色
- 強調時の背景色・文字色
- 強調時の拡大率
- フェードイン時間
- 強調保持時間
- フェードアウト時間
- 4コマンドの表示文字列とコマンドID

## 9. 異常系

- `Camera.main` が一時的に取得できない場合は例外を出さず、そのフレームの追従更新をスキップする。
- HUD 参照が未設定でも `TestSceneVoiceManager` の音声処理を停止させない。
- 未定義または空のコマンドIDを受け取った場合は、全項目を変更せず安全に無視する。
- 同じコマンドIDが複数項目に設定されている場合は警告を出し、最初の項目だけを使用する。
- 日本語文字が欠落した場合に豆腐文字のままリリースしない。フォントアセットを修正してから受け入れとする。

## 10. 受け入れ条件

1. TestScene 開始後、4つの日本語コマンドが視界右側に常時表示される。
2. プレイヤーが頭を動かしても、HUD が滑らかに追従して右側の相対位置を保つ。
3. 各コマンドを発話し、対応リアクションが成立すると、正しい1項目だけが強調される。
4. 認識途中では強調されない。
5. Voice Point 判定でリアクションが不成立になった場合は強調されない。
6. 強調は設定時間後に通常状態へ滑らかに戻る。
7. 連続して別コマンドが成立した場合、最新の項目だけが強調される。
8. 「デフォルト」および未知の認識結果は一覧に表示されず、強調も発生しない。
9. HUD の有無にかかわらず、既存の音声認識とキャラクターリアクションが正常に動作する。
10. Quest 実機で日本語が欠けずに読め、HUD がキャラクター観賞と右手スマホ操作を大きく妨げない。

## 11. 確認用テストケース

| 操作 | 期待結果 |
| --- | --- |
| 「こっち向いて」が成立 | 「こっち向いて」だけを強調 |
| 「手を振って」が成立 | 「手を振って」だけを強調 |
| 「かわいい」が成立 | 「かわいい」だけを強調 |
| 「ユニティちゃん」が成立 | 「ユニティちゃん」だけを強調 |
| トリガー中に部分認識だけ発生 | どの項目も強調しない |
| 認識したが Voice Point 不成立 | どの項目も強調しない |
| 未知語または無音で確定 | どの項目も強調しない |
| 強調中に同じコマンドが再成立 | 同じ項目の保持時間を再開始 |
| 強調中に別コマンドが成立 | 古い項目を解除し、新しい項目だけを強調 |
| HUD 参照を外して再生 | 音声認識とリアクションは正常動作し、例外なし |
