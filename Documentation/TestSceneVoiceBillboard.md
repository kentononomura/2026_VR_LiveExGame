# TestScene 応援電光掲示板

## 現在の構成

- TestSceneの `Stage Voice Billboard` を表面中心のアンカーとして使用する。
- 初期位置はワールド座標 `(-2.4, 1.7, 0.7)`、Y回転180度。観客側の+Z方向を向く。
- `TestSceneVoiceManager` の `VoiceCommandHUD` が、起動時にアンカー配下へCanvasと面取り筐体・金属ベゼル・背面カバー・柱用取付金具を生成する。支柱・台座は生成しない。
- 表面は約1.96m × 1.505m。暗い不透明画面とピンクのアクセントを使用する。
- 「声を届けよう！」と「こっち向いて」「手を振って」「かわいい」「ユニティちゃん」を常時一覧表示する。
- 頭部追従は停止する。音声認識・ポイント判定・コマンド受付条件は変更しない。
- リアクションが実際に開始した項目だけを従来と同じ通知で強調する。表示は音声コマンドを実行するボタンではない。
- デバッグ数値は初期状態で非表示。判定処理・Consoleログは従来どおり。
- 既存の動的日本語TMPフォントと、`VoiceBillboardHousing.mat`・`VoiceBillboardMetal.mat`・`VoiceBillboardDetails.mat`（URP Lit）を使用する。筐体と金属は会場照明に反応し、UIの文字・画面枠は照明に依存しない。外部画像は不要。
- 曲同期、順次表示、LEDドットのテクスチャは今回の対象外。

## Inspectorでの調整

Playを停止してから設定する。

| 対象 | 設定 | 用途 |
| --- | --- | --- |
| Stage Voice Billboard | Transform | 会場内の位置と向き。ローカル-Zが表示面の正面 |
| TestSceneVoiceManager / VoiceCommandHUD | Use Stage Billboard | ONで固定掲示板、OFFで従来の頭部追従 |
| 同上 | Billboard Anchor | 掲示板の表面中心。未設定ならコンポーネント自身のTransformを使用 |
| 同上 | World Scale | 画面サイズ。初期値0.0035 |
| 同上 | Mount Depth | 背面取付アームの長さ。初期値0.28m |
| 同上 | Housing / Metal / Detail Material | 筐体、金属枠・金具、通気スリット・配線のマテリアル |
| 同上 | Show Mounting Hardware | 背面の柱用取付金具と短い配線の表示 |
| 同上 | Screen Brightness | 文字と項目の明るさ。0.4～1、初期値0.9 |
| 同上 | Frame Light Color / Intensity | 細い発光枠の色と強さ。初期強度0.55 |
| 同上 | Show Voice Point Debug | 検証用数値欄を追加。表示面が縦に伸びるため位置も調整する |
| 同上 | Content / Appearance / Highlight Timing | 文言、色、強調時間など |

コンポーネント選択時のシアンのGizmoが表示面の範囲と正面方向を示す。本体と文字はPlay時、または以下の配置プレビューで生成される。
コンポーネントを無効にすると生成した表示と筐体も隠れ、再有効化で強調状態をリセットして再表示する。

## Toolsから見た目を確認して配置を保存する

1. 再生を停止し、TestSceneを開く。
2. `Tools > TestScene > 観客配置・ステージプレビュー` を開く。
3. 「1. ステージプレビューを表示・更新」で、ステージ・Unityちゃんと掲示板の文字・筐体・背面金具を表示する。
4. 「3. 掲示板を表示／選択」で保存対象の `Stage Voice Billboard` を選択する。
5. SceneビューでW（移動）・E（回転）、またはInspectorのTransformで調整する。プレビューはアンカーの子なので、移動・回転・Undo/Redoにも追従する。
6. 「配置をシーンに保存」またはCtrl+SでTestSceneを保存する。このボタンは掲示板だけでなく、シーン内の他の未保存変更も保存する。

文字・寸法・マテリアルの設定を変更した場合は「1. ステージプレビューを表示・更新」を押す。
プレビューは実行時と同じ生成処理を使うが、音声認識やキャラクター動作は実行しない。
プレビューの子を直接編集せず、選択ボタンでアンカーを編集すること。
プレビュー自体はシーン・ビルドに保存せず、削除・更新・Play開始・スクリプト再読み込み・シーンを閉じる際に破棄する。保存したアンカーは残り、Play時の生成位置として使われる。

## 検証

Unity 6000.5.1f1の生成済みコンパイラー設定でEditor向け・Player向けC#コンパイル成功を確認。
Player設定の不足している現行ソース・ログ用参照は検証用の応答ファイルへ補完し、出力はTemp配下に分離した。
これはAPKビルドやUnity上の描画確認ではない。

実機で確認する項目:

1. TestSceneを再生し、会場脇に1台だけ表示されること。頭を左右に向けたり移動しても掲示板が追従しないこと。
2. 開始位置・近距離・離れた観客位置で日本語が読めること。キャラクター、観客、会場設備との重なりを確認する。
3. 4コマンドが成立したとき、それぞれ該当項目だけが光り、元に戻ること。未知語・ポイント不足では光らないこと。
4. 連続発話、コンポーネント無効化・再有効化、シーン往復で二重生成や強調の残留がないこと。
5. スマホのプレビュー・撮影画像での映り込みが意図したものか確認する。
6. 必要に応じてDebugを有効にし、成功・不足の値をConsoleと照合する。

初期位置と文字サイズは仮配置。Questでの可読性と演出中の遮蔽を確認して調整する。

## 柱取り付け型の外観

2026-09-14更新: `Housing Depth Scale` の初期値を0.5にし、筐体・ベゼル・背面金具の奥行きを従来の半分にした。画面の縦横寸法は維持する。以下の奥行き寸法にはこの倍率を掛ける（柱側接触面の初期距離は0.32m）。

- 本体・ベゼル・背面カバー・金具は面取り形状。1台につき44三角形の共通メッシュを1個生成して使い回し、プレビュー破棄時も解放する。
- 背面に通気スリット、モニター側プレート、アーム、柱側プレート、4つの固定ボルト、短い配線を配置する。
- 表示面より約4cm前に縁が出るため、画面が筐体に埋め込まれて見える。
- 柱側プレートの接触面はアンカーのローカル+Z方向に `0.36 + Mount Depth` m。初期値では0.64m。Toolsのプレビューで背面から確認し、接触面を既存の柱表面へ合わせる。必要ならアンカーを柱の子にできる。
- 柱自体や柱までの会場配線は自動生成しない。掲示板の位置・回転は配置ツールで選択したアンカーを使用する。
- 発光枠は細い線と低い不透明度の周辺帯で表現する。常時点滅・スクロール・追加ライト・全画面Bloomは使わず、文字の輪郭を保つ。
- 4つの呼びかけは太字で表示し、成立時の強調通知を維持する。

外観更新時の検証: Editor向け・Player向け・配置ツールのコンパイル成功。実際の形状生成ソースをUnity境界のスタブと組み合わせて検証し、44三角形の向き・非退化、66辺の閉じた接続、メッシュ共有を確認した。Unity上の描画、照明下の材質、Questでの視認性・負荷は未確認。

## 複数モニターの配置と保存

1. Toolsの配置ウィンドウでプレビューを表示する。
2. 「保存対象のモニター」の一覧から配置対象を選ぶ。
3. 「選択した掲示板を複製」を押すと、選択したモニターから横へ0.4mずらしたコピーを追加して選択する。モニター以外を選択していた場合は元の掲示板を複製する。
4. W/EまたはInspectorのTransformで各モニターを移動・回転する。
5. 「配置をシーンに保存」またはCtrl+Sで保存する。複製も含めて次回読み込み・再生時に復元される。

複製ボタンは一時的なプレビューをコピーせず、`VoiceBillboardPlacement` とTransformだけを保存する。表示内容・外観は参照元の `VoiceCommandHUD` を共有し、実行時に全コピーへ成立時の強調とデバッグ表示を通知する。配置の追加・移動はUndo/Redo対応。不要なコピーは一覧から選んでHierarchyで削除し、シーンを保存する。
外観設定変更後はプレビューを更新する。複製にはこのツールのボタンを使用する。
