# TestScene 左手ペンライトの微弱振動

`TestSceneVoiceManager` の `PenlightSwingHaptics` が左手のペンライトを自動取得します。タイトルから引き継いだ永続XRリグにも対応します。TestSceneの終了・コンポーネント無効化時に停止します。

Inspectorで以下を調整できます。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| Amplitude | 0.08 | 振動強度（0〜1）。0で停止 |
| Pulse Duration | 0.06秒 | 1回の振動時間 |
| Pulse Interval | 0.05秒 | 振っている間の送信間隔 |
| Minimum Speed | 0.15 m/s | 移動速度の開始閾値 |
| Minimum Angular Speed | 45度/秒 | 回転速度の開始閾値 |

移動または回転の速度が閾値以上なら振動します。ゲージ加算とは独立しているため、ゲージ満タンや手首だけの振りにも反応します。XRトラッキング空間の姿勢差分を使用し、リグ移動を除外します。1フレームで0.5m以上または90度以上の変化、0.1秒超のフレーム遅延、トラッキング復帰直後は判定を見送ります。

静止、ポーズ、フォーカス喪失、追跡喪失時に微弱振動を停止します。既存のレベルアップ振動（強度0.8、0.3秒）を優先し、その終了後も振っていれば微弱振動に戻ります。振動非対応デバイスでは送信しません。

## 実機確認

- TestScene直接起動とタイトルからの遷移の両方で、左手の移動・手首の回転時に弱く振動する。
- 静止や小さな手ぶれ、右手だけの動きでは微弱振動しない。
- ゲージ満タンでも振動し、レベルアップ時は従来の強い振動が最後まで再生される。
- 振るのを止める、ポーズ、HMDの取り外し、追跡喪失、シーン退出で微弱振動が止まる。
- 再開・追跡復帰時に静止していれば振動せず、次の振りで再開する。

強度の体感は機種に依存するため、実機で Amplitude を調整してください。
